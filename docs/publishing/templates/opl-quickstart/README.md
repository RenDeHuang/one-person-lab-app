# OPL Quickstart Template

State: `reserved`

This template slot is reserved for short setup guides where a full book-style manual is too heavy. It should still use QMD source, a guide manifest, screenshot manifest when images are present, and the shared publishing validation path.

Before activation, define:

- Single-page or short-book Quarto structure.
- Compact callout and command block style.
- HTML/PDF output requirements.
- Required validation checks.

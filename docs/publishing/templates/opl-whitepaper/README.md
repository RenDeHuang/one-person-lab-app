# OPL Whitepaper Template

State: `reserved`

This template slot is reserved for formal OPL whitepapers and institution-facing reports. It should use Quarto source files and a shared OPL style contract instead of a bespoke JSON/PDF renderer.

Before activation, define:

- QMD manuscript structure.
- Cover and version page requirements.
- Citation and bibliography policy.
- PDF engine policy, with Typst or LaTeX selected by verified output quality.
- Required verification checks for figures, tables, links, and secrets.
